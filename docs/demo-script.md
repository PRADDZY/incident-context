# Three-minute silent walkthrough script

**Duration: exactly 03:00 (180 seconds).** Silent: no narration or audio track. The text below is the walkthrough script, with screen actions and short captions. No video, recording, or Loom artifact is part of this deliverable.

Start at the [live Context workbench](https://incident-context.dpratik3005.workers.dev), with the default **Checkout rollout regression · Sandbox** scenario and **Learned graph** selected. Timings describe what remains on screen during each interval; wait out the interval after its action. Use actual returned data. A pending, failed, incomplete, or quota-limited result stays visible at its scheduled checkpoint; do not replace it with a successful example or retry to obtain one.

| Time | Screen action | Silent caption |
| --- | --- | --- |
| 00:00–00:15 | Show **Context workbench**, the request, HydraDB status, and **Selection path**. | **Incident Context** · Complete tool context for platform and on-call agents. HydraDB hackathon · Track 2. |
| 00:15–00:30 | Click the **Northstar Checkout** service node in **Selection path**. Show **Canonical service** and **Resource** below the graph. | Resolve `checkout` to a canonical service and resource before the model runs. Service incidents are simulated. |
| 00:30–00:45 | Expand **Query receipt** below the graph. Scroll within the page to show the engine version, graph version, Cypher, and parameters. | Real HydraDB 0.4.0 queries and returned edges. No in-memory graph fallback. |
| 00:45–01:00 | Collapse **Query receipt**. In **Tool bundle**, expand **deployment_details**, then **JSON schema**. Show its **Requires** line and **Sandbox** label. | A useful tool needs its prerequisites. The graph supplies the complete dependency bundle and exact schemas. |
| 01:00–01:15 | Click **Full catalog**; show the returned schema bytes. Click **Learned graph** and show its returned bytes and **Prerequisites complete** status. | Compare the exact context before paying for a model call. These are live plan bytes, not benchmark averages. |
| 01:15–01:40 | Click **Run agent** once. Scroll to **Agent observations** as the actual response arrives. Keep any actual error visible. | One Workers AI call chooses up to four tools. The backend validates arguments and returns observed evidence. |
| 01:40–01:55 | Expand **deployment_details** in **Agent observations**, if returned; otherwise inspect the actual observation or error that explains the incomplete result. Show the **Observed diagnosis** and usage strip. | Inspect the simulated release evidence, rollback candidate, and actual model usage. Missing usage remains unreported. |
| 01:55–02:10 | Inspect the returned evidence. In **Session learning**, click **Correct** only if it supports the requested result; otherwise click **Incorrect**. If no run returned, leave the disabled controls visible. Expand **Feedback receipt** only if feedback succeeded. | Feedback updates this session's Beta counts. Published benchmark sessions are protected from later feedback. |
| 02:10–02:25 | In **Choose an incident scenario**, select **Search provider observation · Live provider**. Let it compile. Expand **component_status** in **Tool bundle** to show its **Live provider** label. | A second source boundary: read-only Cloudflare public status. Provider reports do not prove an application outage's cause. |
| 02:25–02:40 | Click **Run agent** once. If a run returns, expand **component_status** or **provider_incidents** in **Agent observations** and show its actual timestamp/result; otherwise keep the actual pending/error state. | Timestamped provider evidence, separate from the sandbox service. No outage state is assumed. |
| 02:40–02:50 | Click **Evidence** in the navigation rail. Scroll to **Original strategy comparison** and **Original learning checkpoints**. | Original study: 20/20 graph success with 69.9% fewer schema bytes. Learning curve: flat at 20/20. |
| 02:50–03:00 | Scroll to **Goal-oriented supplement**. Show its curve and attempt/feedback counts. End at 03:00. | Separate goal-oriented supplement: 14/20 → 15/20, then plateau; five failures retained. Full results and source: github.com/PRADDZY/incident-context |

The Evidence view presents the original study and supplement separately. Do not relabel the original curve. The original study has 180 deterministic attempts; the supplement has 160. Its request corpus was authored by a separate AI sub-agent blind to the planner, tools, original corpus, and previous results. Neither curve is LLM accuracy. The live comparison's 7/10, 9/10, and 10/10 outcomes are descriptive; identical frozen/learned inputs in 9/9 comparable pairs prevent attributing their difference to learning. See [results](results.md) for the full methods.

This script uses existing labels and controls from `src/ui/App.tsx`. Its two **Run agent** actions would consume up to two reserved attempts from the shared daily budget. The hackathon's Loom requirement remains unmet without an actual video or an organizer-accepted alternative.
